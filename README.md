🛠️ Technical Stack
This project is built using the latest industry standards to ensure speed and maintainability:

Framework: Next.js (App Router)

Language: TypeScript

Styling: Tailwind CSS

Animations: Framer Motion

Components: shadcn/ui

Icons: Lucide React

Deployment: Vercel

✨ Key Features
Minimalist Design: Inspired by high-end developer portfolios, focusing on readability and whitespace.

Performance First: Near-perfect Lighthouse scores through image optimization and static generation.

Responsive & Fluid: A seamless experience across mobile, tablet, and desktop.

Dark Mode: A sleek, developer-friendly dark interface.

SEO Optimized: Meta tags and structured data ready for search engines.

📁 Project Structure
Plaintext

├── lib/ # Helper functions and shared utilities
├── styles/ # Global styles and Tailwind configuration
└── content/ # (Optional) Data for projects or work history
🚀 Getting Started
To run this project locally, follow these steps:

Clone the repository:

Bash
git clone https://github.com/dejankaravla/portfolio-website.git
Install dependencies:

Bash
npm install
Start the development server:

Bash
npm run dev
Open http://localhost:3000 in your browser.
